# SPEC: 085 — STREAM_SNIFF_ERROR_AGGREGATION

**Фича:** [SNIFF](../../FEATURES/016-SNIFF/FEATURE.md)

| Поле | Значение |
|------|----------|
| Тип | R (refactor) — снижение аллокаций существующего stream-sniff |
| Статус | C (complete) — локальные тесты, race/vet и обе сборки; Android-прогон нового бинаря отдельно |
| Base | `b7eb313f92587b92c417ef02a6c3a80b6aaf738a` |

## Контракт

В одной попытке чтения отклонённые пробы собираются в порядке вызова и
объединяются штатным `E.Errors` один раз, после последнего отклонения.
Первый успешный сниффер немедленно возвращает успех; до первого отклонения
буфер ошибок не выделяется. Повторное чтение по `ErrNeedMoreData`, общий
дедлайн, данные и порядок снифферов не меняются.

Повторное разворачивание, фильтрация и deduplication накопленного дерева
после каждой пробы создавали 124 аллокации для восьми разных отказов.
Изменение касается механики существующей фичи, без нового протокола,
настроек, build-tag или сетевых эвристик.

## Приёмка

- Сохраняются `errors.Is`, порядок текста ошибок и удаление дубликатов.
- Произвольное число снифферов поддерживается без фиксированного лимита.
- Обёрнутый `ErrNeedMoreData` приводит к чтению следующего фрагмента.
- Успех первого сниффера не получает новых аллокаций.
- Пакеты sniff, process, DoH и групп проходят `-race` и `go vet`.
- Базовый и полный Android ARM64 наборы тегов собираются.
- До/после измеряются на одном базовом коммите и одинаковых тестах;
  микробенчмарк не считается доказательством уменьшения сетевой задержки.
