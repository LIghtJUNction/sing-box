# План

Добавить `route/network_missing_interface_lx.go`: обработчик `nil`,
отмена старого контекста и узкая проверка режима Android system routing.
В `route/network.go` оставить один помеченный вызов обработчика.

Проверить режимы через настоящий pause manager, отсутствие вымышленного
интерфейса, повторную потерю, отмену контекста и callback восстановления.
Host-тест использует синтетические интерфейсы; Android-сборка проверяет
компиляцию фактической платформенной ветки.

Зона возможного конфликта с upstream — только `nil`-ветка
`NetworkManager.dispatchInterfaceUpdateLocked`. Публичные options и
зависимости не меняются.
